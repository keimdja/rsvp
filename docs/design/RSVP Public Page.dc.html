1Three themes · 375 px

Same template, same fields. Card layout puts the invite on top and the details in a card; poster lets the invite fill the first screen and the card rises over it. The form always sits on a surface, so it stays legible over any background. Frames are interactive: pick a reply, submit empty to see validation.
